# 🎯 Course Outcomes

At the end of the course, students will be able to:

| CO | Course Outcome | Knowledge Level |
|----|---------------|-----------------|
| **CO1** | Understand application development and analyze the insights of object-oriented programming to implement applications. | K2, K4 |
| **CO2** | Understand, analyze and apply overall modelling concepts such as system and structural modelling. | K2, K3 |
| **CO3** | Understand, analyze and apply OOP concepts such as abstraction and inheritance. | K2, K3, K4 |
| **CO4** | Understand the basic concepts of C++ to implement object-oriented concepts. | K2, K3 |
| **CO5** | Understand the object-oriented approach to solve real-world problems. | K2, K3 |
